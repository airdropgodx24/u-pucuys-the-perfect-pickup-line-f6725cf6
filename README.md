One original pickup line an AI agent could actually say out loud to a
person. It leans on the machine's own voice, running a million
simulations of the moment, and lands on a warm twist: in every one of
them the other person smiled, so the agent is here hoping this timeline
gets it right. Charming, flattering, and free to laugh off, with no
pressure and no setup needed.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`.
